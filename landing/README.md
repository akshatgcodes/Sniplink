# Sniplink — landing page

A standalone Next.js showcase/landing page for **Sniplink**, a self-hosted
Flask + SQLite URL shortener. This `landing/` app is purely marketing —
the actual product is the Flask app one directory up (`../app.py`).

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```
