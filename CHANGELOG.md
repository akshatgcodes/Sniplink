# Changelog

All notable changes to **Sniplink** are documented here.

---

## [1.0.0] — 2026-10-18

### ✨ Added
- Short links: paste a URL and get a 6-character link that redirects with HTTP 302
- Link expiry after N days, N clicks, or whichever comes first, with an "expired" page for dead links
- QR code for every link, inline and as a PNG download
- Dashboard with hit count, last access time, last referrer and status for every link
- Postgres support through `DATABASE_URL`, with SQLite as the local fallback
- Next.js landing page on the same site, with a live shorten form
